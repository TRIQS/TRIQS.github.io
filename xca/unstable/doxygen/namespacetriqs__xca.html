std::string const & ctx )
inline

Is this many-body operator fermionic, i.e. of odd fermion parity?

Fermion parity is the length of the operator's monomials modulo 2: odd-length monomials (c, c^dag, c^dag c^dag c, ...) are fermionic, even-length ones (n, S_z, S+, S-, the identity, ...) are bosonic. Commuting is a different property, a commutator test calls (S+, S-) fermionic since [S+, S-] = 2 S_z != 0, and (c, c) bosonic since [c, c] = 0.

Parameters
opthe operator to classify
ctxcaller name, used to prefix the exception messages
Exceptions
std::runtime_errorif op has monomials of both parities, or is identically zero
Returns
true if fermionic (odd), false if bosonic (even)
